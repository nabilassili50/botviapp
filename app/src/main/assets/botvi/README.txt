2) Shizuku: شغّله (Wireless debugging) ثم "Use Shizuku in terminal apps" وصدّر rish و rish_shizuku.dex إلى ~/ ثم:
   mkdir -p ~/bin && mv ~/rish ~/rish_shizuku.dex ~/bin/ && chmod +x ~/bin/rish
   (وأضف في rish السطر: export RISH_APPLICATION_ID=com.termux) ثم: export PATH=$PATH:~/bin

   nohup python panel.py > panel.log 2>&1 &
